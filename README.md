# Personal Portfolio Website

A personal portfolio website showcasing my background as a Computer Science and Engineering student, my projects, and my competitive programming journey.

## 🌐 Live Website

**Portfolio:** [View My Portfolio](https://tasfialaisa123.github.io/C243446_PersonalPortfolio/)

## 📌 About the Project

This portfolio website presents my technical skills, programming experience, academic journey, and projects in one place. It provides visitors with an overview of my work and links to my competitive programming profiles.

The website is designed with a clean layout, responsive sections, and easy navigation.

## ✨ Features

- **Home Page:** Introduction and overview of my portfolio.
- **Competitive Programming Journey:** Information about my problem-solving experience and programming progress.
- **CP Profiles:** Links to my profiles on different online judges.
- **Projects Page:** Displays my projects and their descriptions.
- **Project Management:** Add, edit, and delete project entries using JavaScript and browser local storage.
- **Responsive Design:** Layout adapts to different screen sizes.
- **Navigation:** Easy access to the different sections and pages.

## 💻 Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Tasfialaisa123/C243446_PersonalPortfolio.git
   ```

2. Open the project folder:

   ```bash
   cd C243446_PersonalPortfolio
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No additional package installation is required for the basic website.
